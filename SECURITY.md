# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security issue or vulnerability in AuraJobs, please report it responsibly by opening a private security advisory on GitHub or reaching out directly to the maintainers rather than creating a public issue.

We will review and respond to all legitimate reports promptly.
